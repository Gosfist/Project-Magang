Isolir dengan IP Pool Khusus

Pelanggan isolir tetap terhubung PPPoE dengan IP khusus. Pembayaran yang sudah di-ACC atau janji bayar mengembalikan atribut pool internet. Perubahan sesi menggunakan RADIUS Disconnect.

Pasang pool, profil dan firewall dari script sebelum mengaktifkan mode ini. Konfigurasi perangkat perlu diperiksa langsung melalui Winbox; aplikasi hanya menyimpan pengaturan dan menerima accounting.

Daftarkan pool terpisah di Kelola IP Pool, misalnya 192.168.100.2-192.168.100.254, lalu pasang script-nya. Pool ini tidak digunakan pada Harga Paket.

Script mengatur profil isolir tanpa IPv6 dan tiga rule drop sebelum accept/FastTrack. Setelah pemasangan dikonfirmasi, backend menyinkronkan RADIUS dan mengirim Disconnect untuk sesi dengan IP yang belum sesuai. Menonaktifkan mode ini mengembalikan isolir ke penolakan login; rule pada perangkat tetap perlu dikelola melalui Winbox.
