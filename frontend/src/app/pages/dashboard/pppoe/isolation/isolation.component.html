Isolir dengan IP Pool Khusus

Pelanggan isolir tetap terhubung PPPoE. Router memberi IP dari pool isolir dan memblokir trafiknya. Pembayaran yang sudah di-ACC atau janji bayar membuka kembali pool internet.

Buat pool terpisah melalui Kelola IP Pool, misalnya 192.168.100.2–192.168.100.254. Pool ini tidak digunakan pada Harga Paket.

Terapkan akan membuat profil PPPoE isolir tanpa IPv6 dan tiga rule drop sebelum accept/FastTrack: trafik keluar, trafik masuk, serta akses ke router. Sesi dengan IP yang tidak sesuai disambungkan ulang satu kali. Menonaktifkan mode ini mengembalikan isolir ke penolakan login.
