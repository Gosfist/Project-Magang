Klien VPN WireGuard

Cara menggunakan
  1. Pasang konfigurasi WireGuard dari VPS / penyedia pada server RADIUS dan MikroTik RouterOS 7. Pastikan kedua perangkat bisa saling menjangkau melalui IP VPN.
  2. Tambahkan perangkat Server RADIUS dengan IP VPN server. Kemudian tambahkan setiap MikroTik dengan IP VPN masing-masing. Gunakan IP perangkat, tanpa subnet / CIDR.
  3. Di Router / NAS pilih klien WireGuard MikroTik. IP API dan IP NAS terisi otomatis. Isi akun API dan secret RADIUS, lalu simpan.
  4. Jalankan Script RADIUS dari Router / NAS. Alamat tujuan memakai IP VPN Server RADIUS yang dicatat di sini.
  5. Izinkan API MikroTik, RADIUS, dan CoA melalui VPN. Gunakan Cek Router, lalu uji dial PPPoE untuk memastikan autentikasi dan accounting bekerja.

Penyedia VPN perlu mengizinkan komunikasi antarperangkat. VPN untuk akses internet saja belum tentu menyediakan akses Server RADIUS ke MikroTik.
