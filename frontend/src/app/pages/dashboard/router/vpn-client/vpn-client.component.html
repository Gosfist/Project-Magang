Ubuntu RADIUS dan semua MikroTik memakai satu Network ID. Maksimal 10 perangkat: satu Ubuntu dan hingga sembilan perangkat lain. Pelanggan PPPoE tidak memakai slot ZeroTier bila tidak ikut jaringan ini.

Hitungan ini berdasarkan pencatatan web. Catat juga laptop/HP yang ikut jaringan, dan cocokkan dengan anggota di ZeroTier Central. Menonaktifkan atau menghapus catatan tidak mencabut otorisasi jaringan.

Panduan setup Ubuntu VirtualBox dan MikroTik
  1. Buat jaringan Private di ZeroTier Central. Pilih subnet yang tidak bertabrakan dengan LAN atau pool PPPoE. Catat Network ID 16 karakter.
  2. Pasang ZeroTier di dalam VM Ubuntu. Pertahankan Bridged Adapter bila web tetap diakses lewat IP LAN; VM harus bisa mengakses internet. Menjalankan ZeroTier di host Windows saja belum menghubungkan Ubuntu.
  3. Tambah klien jenis Ubuntu / Linux dan centang Server RADIUS. Buka Script Setup untuk perintah join. Authorize node di Central, tetapkan Managed IP tetap, lalu isi Node ID dan IP ZeroTier ke form ini.
  4. Untuk setiap MikroTik RouterOS 7 ARM/ARM64, pasang paket zerotier dengan versi yang sama dengan RouterOS dan periksa device-mode. Tambah klien MikroTik, jalankan Script Setup lewat WinBox/Terminal lokal sekali, lalu authorize node dan catat IP serta Node ID di web.
  5. Setelah IP Ubuntu tersimpan, unduh ulang script MikroTik untuk rule API/CoA khusus server. Jika API memakai address whitelist, tambahkan IP ZeroTier Ubuntu /32 pada whitelist yang ada.
  6. Di Router / NAS, pilih klien ZeroTier MikroTik. IP API dan IP NAS otomatis memakai IP klien tersebut. Isi akun API dan secret RADIUS, lalu jalankan Script RADIUS dari halaman Router / NAS.
  7. Di Ubuntu, izinkan UDP 1812/1813 dari IP ZeroTier tiap MikroTik pada interface ZeroTier. Pastikan FreeRADIUS mendengarkan alamat itu dan membaca NAS dari SQL; validasi konfigurasi lalu reload/restart FreeRADIUS setelah perubahan NAS sesuai konfigurasi server.
  8. Gunakan Cek Router untuk memeriksa API/network/IP. Lakukan dial PPPoE sungguhan untuk memastikan RADIUS, accounting dan pemutusan sesi bekerja. Data aktif di tabel bukan status online perangkat.

Paket Personal gratis Central saat ini tidak menyediakan API. Join awal dan persetujuan anggota dilakukan di perangkat/Central; konfigurasi penuh sekali klik dari web memerlukan API Central pada paket yang mendukungnya.
