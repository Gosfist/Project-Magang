Script Darurat per Router

Isi gateway dan nama profil dasar yang sudah digunakan pada router. Referensi pool diambil dari pendaftaran web, sehingga pool dan profil dasarnya harus sudah dipasang melalui Terminal Winbox. Profil cadangan menyalin pengaturan dasar seperti DNS/parent queue, lalu memakai pool dan limit Harga Paket. Script memeriksa ketersediaannya saat dijalankan; aplikasi belum memeriksa perangkat. Menyimpan pengaturan atau mengunduh file belum mengubah MikroTik.

Untuk script lokal, centang agar sesi akun cadangan langsung memakai mode lokal. Script kembali ke RADIUS selalu menyambungkan ulang sesi akun backup satu kali untuk membersihkan sesi lokal beserta queue dinamisnya.

Saat gangguan, paste script lokal pada router yang dipilih. Setelah RADIUS pulih, script kembali menghapus seluruh konfigurasi khusus backup: secrets, profil dan rule firewall UNZANET-BACKUP pada router terpilih. Terminal melaporkan hasil pembersihan dan konfigurasi yang belum dapat dihapus. Pool dan profil dasar sudah tersedia sebelum import; konfigurasi asli dan isolir utama tetap dipakai RADIUS. Unduh ulang kedua script setelah pembaruan ini. Akun isolir memakai pool isolir jika mode tersebut aktif; jika belum, akun isolir tetap nonaktif pada cadangan lokal. Status mengikuti saat file diunduh; unduh ulang setelah perubahan akun. Billing web tidak memperbarui secrets saat mode lokal digunakan.

Backup dan Template Excel

Backup data akun dan kredensial PPPoE. Invoice, pembayaran, foto, PSB, dan janji bayar tidak disertakan. Template memuat petunjuk serta referensi paket/router/area/ODP.
